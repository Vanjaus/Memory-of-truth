# Memory of Truth

**Long-term AI memory under its owner's control.**

Memory of Truth is a project in development. Its goal is to let people keep a durable memory that can be used across different AI models and agents without giving any model the authority to rewrite the owner's history.

The central rule is simple: an AI may suggest a memory, but only the owner can approve a canonical record. Records should retain their source, attribution, time context, and revision history. The owner should be able to export and restore their memory.

## Where the project stands

We are developing and testing the memory system. **There is no public download or open testing program yet.** We will announce a test release only when the project is ready for people to install and evaluate it. We have not announced a release date.

The memory engine's source code is private at this stage. This repository is the public home for the project description, progress updates, questions, and community feedback. Publishing this repository does not make the engine open source.

## Planned path

1. Explain the project and listen to potential users.
2. Continue development and verify the complete memory cycle, including recall, owner approval, and recovery.
3. Announce a controlled test release with installation and testing instructions when it is ready.
4. Use real tester feedback to shape a stable V1.
