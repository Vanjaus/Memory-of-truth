# Roadmap

This roadmap describes the intended sequence of work. It is not a release schedule or a list of features already available to the public.

## Now: development and public discussion

- Continue building and evaluating the memory system.
- Define the first experience that a tester can install and use.
- Invite questions, integration requests, and expressions of interest through GitHub Discussions.
- Keep the engine source code private while the public documentation is prepared.

## Next: first test release

When the project is ready, we plan to publish a working test build and clear installation and testing instructions. The first test should cover the full cycle: a conversation produces a proposed memory; the owner approves a canonical record; a later conversation can retrieve it with its source and status; and the memory can be backed up and restored.

We will publish supported platforms, known limitations, test tasks, and release notes with the build. We have not announced a date.

## Later: V1 and beyond

Our intended commercial model is a one-time purchase for a major version, with updates within that version. Existing owners would receive a discounted path to a later major version. Self-hosting on the user's own computer or VPS remains central to the plan. A managed cloud service may be offered later as an optional subscription.

Store availability, prices, support periods, and implementation details will be announced only when they are defined and verified.
