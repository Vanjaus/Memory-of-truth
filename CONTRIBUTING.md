# Contributing ideas and feedback

We welcome questions and suggestions while Memory of Truth is in development. This repository is currently for public documentation and discussion; it does not contain the private memory engine or a public test build.

Use [GitHub Discussions](https://github.com/Vanjaus/Memory-of-truth/discussions) for product ideas, use cases, integration requests, and interest in future testing. Once a test build is available, we will publish separate instructions for reproducible bug reports.

Please describe the problem you want solved and the result you would expect. Synthetic examples are welcome. Do not share private memories, credentials, API keys, or material you do not have the right to publish.

Participation in a discussion does not enroll you as a tester or assign VIP status. The founding tester rules will be published before enrollment opens.
