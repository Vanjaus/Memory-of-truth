# Future founding testers

We are collecting interest in an early test program. **Applications and downloads are not open yet.**

The project plans to recognize its first GitHub testers as founding VIP testers. The intended benefit is a permanent license for commercial V1, including updates within V1, and early access to test V2 before its public release. Early V2 testing does not itself include a permanent V2 license. Existing V1 owners are intended to receive a discount if they choose to buy a later major version.

We will publish eligibility, enrollment dates, participation expectations, and the applicable test terms before accepting testers. Commenting now does not automatically grant VIP status or a license.

## Express interest

In [GitHub Discussions](https://github.com/Vanjaus/Memory-of-truth/discussions), you can tell us:

- Which operating system and installation style you would want to test: local computer or your own VPS.
- Which AI models, agents, or applications you would want to connect.
- Which memory problem matters most to you: recall, attribution, history, portability, or something else.
- Whether you would consider testing an early version when one is available.

Please keep examples synthetic. Do not publish real private memories, account details, credentials, or API keys.
