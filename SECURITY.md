# Security and private data

There is no public software release in this repository yet. Please do not post credentials, API keys, owner-held keys, private memories, or personal data in Issues, Discussions, or pull requests.

If you find an exposed secret or a security issue in material published here, report it privately to the maintainers through GitHub's private vulnerability reporting feature if it is enabled for this repository. Do not include exploit details or sensitive data in a public post. If private reporting is unavailable, open a public discussion asking for a private contact method without disclosing the issue itself.

Security guidance for future software builds will be published with those builds.
