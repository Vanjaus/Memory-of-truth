# Licensing direction

Memory of Truth is still in development. **This page explains the intended product model; it is not a software license or an offer to sell or enroll.** The engine's source code and binaries are not published in this repository.

The current plan is:

- Early development testing will be free for selected testers using their own computer or VPS and, where needed, their own third-party AI API accounts.
- Founding GitHub VIP testers will receive a permanent commercial V1 license, including V1 updates, under eligibility and test terms that will be published before enrollment.
- Other users will be able to buy a major version once a commercial release exists. Updates within that major version are intended to be included.
- A later major version may be purchased separately, with a discounted upgrade for existing owners. Owners can continue using the major version they bought, subject to its published support and compatibility terms.
- A managed cloud service, if offered in the future, will be optional and subscription based. Self-hosted use will remain part of the product plan.

The exact beta terms, commercial license, support period, prices, and distribution rules have not yet been published. No particular open-source license has been selected for the engine. Public visibility of this documentation does not grant permission to use or distribute unreleased software.
